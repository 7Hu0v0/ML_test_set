# Machine Learning Test Set

黑白风格的机器学习基础刷题网页。

在线访问：

https://7hu0v0.github.io/ML_test_set/

## 功能

- 70 道机器学习题，10 题一组练习
- 支持单选、多选、判断题
- 按题集、题型、知识点筛选
- 搜索、随机顺序、只看错题
- 本地保存答题进度
- 提交后显示答案与简要解析
- 错题导出到剪贴板

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：黑白视觉样式
- `script.js`：交互逻辑
- `data.js`：题库数据
